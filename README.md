# SavvyFinance - Financial Education Website

A professional financial education website built with React, designed for AdSense approval and SEO optimization.

## Features

- **Professional Design**: Clean, trustworthy styling inspired by leading financial websites
- **Legal Compliance**: Complete legal pages (Privacy Policy, Terms of Service, Cookie Policy)
- **SEO Optimized**: Structured for search engine optimization
- **AdSense Ready**: All required pages and disclaimers for Google AdSense approval
- **Responsive**: Mobile-first responsive design
- **Contact Form**: Functional contact form with validation

## Pages Included

- **Homepage**: Hero section with clear value proposition
- **About Us**: Company story and mission
- **Contact**: Contact form and information
- **Privacy Policy**: GDPR/CCPA compliant privacy policy
- **Terms of Service**: Comprehensive terms with financial disclaimers
- **Cookie Policy**: Detailed cookie usage and management

## Tech Stack

- **Frontend**: React 19, Tailwind CSS, Shadcn/UI
- **Icons**: Lucide React
- **Fonts**: Inter (Google Fonts)
- **Build Tool**: Create React App with CRACO
- **Deployment**: Optimized for Netlify
